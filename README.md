A fan-made recompilation project for the original Battle Arena Toshinden released for the Game Boy.

This project recreates the game using modern development tools while requiring the user to provide their own copy of the original game ROM.

Important: This project does not include, distribute, or provide a ROM file. You must provide your own legally obtained ROM to play the game.

Features
Recompiled version of Battle Arena Toshinden
Requires the original Game Boy ROM supplied by the user
Keyboard controls
Full-screen support
Designed primarily for Windows
ROM Requirements

The game does not include a ROM file.

To play:

Obtain your own copy of the original Battle Arena Toshinden Game Boy ROM.
Launch the game.
When prompted, select/provide your ROM file.
The game will load the supplied ROM.

Please do not ask the project maintainer for a ROM.

Controls
Keyboard Key	Function
X	A Button
Z	B Button
↑ ↓ ← →	Move / Navigate
F1	Toggle Fullscreen
Alt + Enter	Toggle Fullscreen
Platform Support

Windows is currently the only officially supported platform.

Linux and Steam Deck

Linux and Steam Deck users are welcome to try running the Windows version through compatibility software such as Wine or Proton.

For Steam Deck users, you can try adding the executable as a Non-Steam Game and enabling a Proton compatibility tool.

Linux users can similarly try running the Windows executable through Wine or another compatible Windows runtime.

However, compatibility with Wine, Proton, SteamOS, Arch Linux, or other Linux distributions is experimental and not officially supported at this time.

If you get the game working on Linux or Steam Deck, reporting your configuration and results can help determine whether official support can be added in the future.

Compatibility Testing

If you are using Linux or Steam Deck, try the following:

Run the Windows version through Wine

Run the Windows version through Proton

Test keyboard controls

Test fullscreen with F1

Test fullscreen with Alt + Enter

Test loading your own ROM

Report whether the game works correctly
